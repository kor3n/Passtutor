PassTutor
=======

**Password Tutor - A tool for remembering passwords... Using your mind :)**

Updates [1.1.2]
------------

* Remove the need to import a pip libary(python-dotenv), replaced with argeparse.
* Supports now Windows and Linux, clear screen function.
* Fixed some sytax for better type hinting.
* Removed `.env` and `requirements.txt` as they are no longer needed.


Goal
------------

I wanted to remember passwords without writing them down or using a password manager.


Running
------------

`python passtutor.py`

`python passtutor.py -h`

`python passtutor.py -l LOOK_TIME`


Requirements
------------

* Windows, Linux both now work. Should also work for MACOS but I dont have one.
* python 3.6+
